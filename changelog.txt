x12.5.3
==========
评分开关
- 新增评分同步开关：影评人评分、豆瓣评分、音乐评分可单独关闭，社区评分由「社区评分来源」控制。
- 「社区评分来源」新增「不同步」选项，选中后不再写入社区评分；豆瓣与影评人评分不受影响。
- 「不标注」更名为「未知来源」，取值仍为 default，已有配置不受影响。
- 豆瓣评分默认关闭，其余开关默认开启；升级后行为与 12.5.2 一致。
- 移除「主来源选豆瓣但条目无豆瓣分时退回未知来源」的逻辑：StrmAssistant 会把豆瓣分覆盖进社区评分，原逻辑会把真实豆瓣分误降级。
- 评分设置从「播放」分类移至「同步」分类，并补齐四项设置的帮助说明。
- 关闭某项评分后不再写入，已有评分在条目下次刷新时移除；更新时仍只清理受管的 6 种评分类型。
- 评分来源选项改用字符串 ID 写法，修复 Kodi 22 下 TMDb、IMDb 不显示。
- 移除 Trakt 选项；豆瓣帮助的 msgid 与英文版对齐，修正该条回退英文。

x12.5.2
==========
基于 12.5.1 精简魔改版。

评分
- 新增主评分来源设置（TMDb / IMDb / Trakt / 豆瓣 / 不标注），社区评分按所选类型写入。
- 将 Emby 影评人评分同步为 tomatometerallcritics，覆盖电影、剧集、单集、音乐视频和其他视频。
- 将 Emby 条目中的豆瓣评分同步为 douban 类型。
- 主评分选豆瓣但条目没有豆瓣分时，社区评分退回不标注。
- 构建 Kodi uniqueid 时跳过 *Rating 这类 ProviderId。
- 评分选项与帮助文案改为本地化短句。

同步与元数据
- 修复音乐艺术家收藏的子内容同步：多内容 ID 解析不再越界，缺失服务器 / 映射时安全跳过。
- 启动同步按库隔离失败：单个库查询失败不影响其他库；失败时保留同步检查点，下次继续重试。
- 单集 uniqueid 优先使用 TMDb，缺失时回退 TVDb。
- 启动同步在关机或异常时回滚检查点；回滚的数据库锁等待上限 5 秒，避免阻塞关机。

维护
- 新增 GitHub Actions：core 分支版本号变化时自动打包并发布 Release，发布说明取自 changelog。

12.5.1
==========
基于官方 Emby for Kodi Next Gen 12.5.1 的精简魔改版，完整说明见 README。

播放
- 使用 Emby 静态 HTTP 流，并跟随原始 HTTP(S) 媒体 URL；保留 ISO、蓝光与 DVD 直读路径。
- 版本组无变化时原位更新，保留电影 / 文件 ID、默认版本和本地流信息；源按名称排序，[Default] 优先。
- 新增剧集选版与跨季连播：记住同季选版，支持 Kodi 起播前选版，手动选择优先。
- 遵循 Kodi 字幕语言与可见性设置；片头 / 片尾提示精简，续播倒计时单位修正。
- 设置提供清理图片缓存与压缩数据库。

接口
- 剧集选版 API：`/api/v1/episodes/`（versions / resolve / media）。
- Similar API：`/api/v1/items/similar`，仅返回已同步的电影与剧集条目。

同步与元数据
- 四路启动同步；单个库查询失败不影响其他库，失败时保留 UTC 检查点。
- 分页统一为默认 100 条，单集、歌曲与音乐艺术家 1,000 条；减少重复查询与队列分配。
- 电影与剧集默认使用 TMDb ID，单集使用 TVDb；社区评分存为 default，不同步影评人与豆瓣。
- 演职人员、Studio、按需图片与章节、原生库入口、收藏范围按精简规则同步。

修复
- 实时观看与收藏、续播与外挂字幕、选版与会话、HTTP 与光盘路径、WebSocket 重连、上游流信息。

精简
- 移除动态浏览与搜索、一起看、直播 / PVR、照片、离线下载、主题媒体、影院预告和转码。
- 移除旧播放模式、WebDAV / 路径替换 / 转码、主动删除、备份恢复、去重工具等。
- 仅保留英文与简体中文本地化；更新记录见 README 与 changelog.txt。
