x12.5.1.1
==========
Based on Emby for Kodi Next Gen 12.5.1.

Playback
- Use Emby static HTTP streams and follow original HTTP(S) media URLs. Retain direct ISO, Blu-ray and DVD paths.
- Update unchanged movie version groups in place, preserving Kodi movie and file IDs, the selected default version and local stream details.
- Sort sources by name with [Default] first. Resolve manual version selection from the selected Kodi item, remember episode choices and optionally prefer the highest resolution when no manual or remembered choice applies.
- Respect current Kodi subtitle language and visibility settings, with an unknown-language external subtitle fallback and restoration of the existing selection when no match is found.
- Use compact intro and credits skip prompts and correct the resume rewind unit conversion.

Sync and metadata
- Fetch startup changes with up to four persistent connections while preserving ordered processing and UTC sync checkpoints.
- Centralize sync paging at 100 items by default and 1,000 for episodes, songs and music artists. Reduce repeated database reads and queue allocations during sync.
- Restore live watched, resume and favourite updates when Emby omits the media type. Keep standard Emby casting and reconnect WebSocket sessions after server disconnects.
- Use TMDb as the default movie and series ID and TVDb for episodes. Store Emby community scores as the generic default rating while preserving Kodi user ratings.
- Load artwork and chapter images on demand using built-in size and quality profiles. Simplify artwork, cast and studio sync.

Scope and settings
- Focus on media synced to Kodi. Remove dynamic browsing and search, watch parties, Live TV/PVR, photos, offline downloads, theme media, cinema trailers and transcoding.
- Remove legacy playback modes and unused settings, actions and resources. Keep English and Simplified Chinese translations.
