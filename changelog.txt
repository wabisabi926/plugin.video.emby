x12.5.3
==========
评分开关
- 新增评分同步开关：影评人评分、豆瓣评分、音乐评分可单独关闭，社区评分由「社区评分来源」控制。
- 「社区评分来源」新增「不同步」选项，选中后不再写入社区评分；豆瓣与影评人评分不受影响。
- 「不标注」更名为「未知来源」，取值仍为 default，已有配置不受影响。
- 豆瓣评分默认关闭，其余开关默认开启；升级后行为与 12.5.2 一致。
- 移除「主来源选豆瓣但条目无豆瓣分时退回未知来源」的逻辑：StrmAssistant 会把豆瓣分覆盖进社区评分，原逻辑会把真实豆瓣分误降级。
- 评分设置从「播放」分类移至「同步」分类，并补齐四项设置的帮助说明。
- 关闭某项评分后不再写入，已有评分在条目下次刷新时移除；更新时仍只清理受管的 6 种评分类型。

x12.5.2
==========
基于 12.5.1 精简魔改版。

评分
- 新增主评分来源设置（TMDb / IMDb / Trakt / 豆瓣 / 不标注），社区评分按所选类型写入。
- 将 Emby 影评人评分同步为 tomatometerallcritics，覆盖电影、剧集、单集、音乐视频和其他视频。
- 将 Emby 条目中的豆瓣评分同步为 douban 类型。
- 主评分选豆瓣但条目没有豆瓣分时，社区评分退回不标注。
- 构建 Kodi uniqueid 时跳过 *Rating 这类 ProviderId。
- 评分选项与帮助文案改为本地化短句。

同步与元数据
- 修复音乐艺术家收藏的子内容同步：多内容 ID 解析不再越界，缺失服务器 / 映射时安全跳过。
- 启动同步按库隔离失败：单个库查询失败不影响其他库；失败时保留同步检查点，下次继续重试。
- 单集 uniqueid 优先使用 TMDb，缺失时回退 TVDb。

维护
- 新增 GitHub Actions：core 分支版本号变化时自动打包并发布 Release，发布说明取自 changelog。

12.5.1
==========
基于官方 Emby for Kodi Next Gen 12.5.1 的精简魔改版。

播放
- 使用 Emby 静态 HTTP 流，并跟随原始 HTTP(S) 媒体 URL；保留 ISO、蓝光与 DVD 直读路径。
- 版本组无变化时原位更新，保留 Kodi 电影 / 文件 ID、默认版本和本地流信息。
- 源按名称排序，[Default] 优先。手动选择版本时以所选 Kodi 条目为准，记住剧集选择；无手动或记忆选择时可优先最高分辨率。
- 遵循 Kodi 当前字幕语言与可见性设置；未知语言外挂字幕回退，找不到匹配则恢复原选择。
- 精简片头 / 片尾跳过提示，修正续播倒计时单位换算。

同步与元数据
- 启动同步最多使用四路持久连接，保持顺序处理与 UTC 同步检查点。
- 同步分页统一为默认 100 条，单集、歌曲与音乐艺术家 1,000 条；减少同步期间重复数据库读取与队列分配。
- Emby 未返回媒体类型时，恢复实时已看、续播与收藏更新；保持标准 Emby 投射，并在服务器断开后重连 WebSocket。
- 电影与剧集默认使用 TMDb ID，单集使用 TVDb；社区评分存为 default 类型，保留 Kodi 用户评分。
- 按需加载封面与章节图，使用内置尺寸和质量档；简化封面、演员与工作室同步。

范围与设置
- 聚焦已同步到 Kodi 的媒体；移除动态浏览与搜索、一起看、直播 / PVR、照片、离线下载、主题媒体、影院预告和转码。
- 移除旧播放模式及未使用的设置、动作与资源。
- 移除插件截图、旧的上下文 / 续播对话框与多余皮肤素材；保留登录、服务器连接和片头 / 片尾跳过对话框。
- 仅保留英文与简体中文本地化。
